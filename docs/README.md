# Документация «Взаимно»

«Взаимно» — платформа обратного подбора ИТ-специалистов с верифицированным профилем ФСП. Кандидат проходит опрос и адаптивный тест на одноразовых заданиях и получает категорию «специализация × грейд»; работодатель описывает потребность текстом с обязательной зарплатной вилкой и получает слепую объяснимую подборку; контакты раскрываются только после взаимного «да» и отдельного согласия кандидата. Достижения ФСП усиливают профиль, но не открывают дверь: кандидат без истории ФСП проходит тот же путь и не штрафуется.

Этот каталог — сопроводительная документация решения. Порядок документов повторяет логику знакомства с системой: от устройства и главных механик к проверке результатов, интеграции, API, составу и запуску.

## Соглашения

- **«В разработке»** — функция описана, но в коде ещё не построена или построена частично. Такие места перечислены в разделе «Статус реализации» [ARCHITECTURE.md](ARCHITECTURE.md) п. 9 и в соответствующих документах.
- Диаграммы записаны в Mermaid (C4, ERD, sequence, state) и отображаются на GitHub, GitLab и в большинстве редакторов Markdown.
- Тексты интерфейса и сообщения API — на русском; идентификаторы, поля API и переменные окружения — на английском (`VZ_*`).
- Все числа параметров берутся из `config/*.yaml`; если число в документе расходится с конфигом, верно значение конфига.
- Данные демо вымышленные: компании, люди, спортсмены и номера ЕКП. Реальных брендов и ФИО нет.
- Численные результаты валидации — симуляция: она проверяет процедуру, не реальных людей. Ограничения сформулированы в каждом разделе.

## Актуальность

Документы описывают состояние репозитория на 05.10.2026 (ветка `main`). Фронтенд, банки заданий QA и DevOps, подключение «Антиподсказчика» к выдаче заданий и «Сигнал интереса» ещё в разработке: по мере готовности соответствующие разделы документов нужно обновить (в тексте такие места помечены).

## Откуда взяты утверждения

Документы написаны по коду и конфигурации репозитория (`backend/app`, `services/fsp-mock`, `deploy/keycloak`, `config/*.yaml`, `docker-compose.yml`, `backend/pyproject.toml`, `backend/uv.lock`, `frontend/package.json`), а списки эндпоинтов и версий библиотек сформированы автоматически из OpenAPI приложения и lock-файлов. Проверка: `cd backend && uv run pytest -q` (тесты), `uv run python -m eval.validate` (валидация), `uv run python -c "import json; from app.main import app; print(json.dumps(app.openapi(), ensure_ascii=False))"` (схема API).
