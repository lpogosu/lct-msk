# Требования задачи и где они реализованы

Таблица для жюри: что требуется от решения, где это сделано и как проверить за минуту. Формулировки сокращены и пересказаны. Статус «частично» означает, что у пункта есть оговорка, она написана в той же строке.

Как поднять стенд: [README](../README.md), [DEPLOY.md](DEPLOY.md). Без регистрации откройте `/jury`. Демо-логины: `make creds`. Swagger: `/api/docs`.

## 1. Кабинет кандидата

| Требование | Где реализовано | Как проверить | Статус |
|---|---|---|---|

| Обязательный путь: опрос по направлению, выбор грейда, тест, категория | `/candidate/survey` → `/candidate/grade` → `/candidate/test/{id}` → `/candidate/result/{id}` | Пройти путь как Илья или как одноразовый кандидат с `/jury` | выполнено |
| Категория = специализация × грейд; ранг внутри категории по тесту и достижениям ФСП | `config/taxonomy.yaml`; `backend/app/matching/scoring.py`; [MATCHING.md](MATCHING.md) | Открыть подборку, раздел «Из чего сложился Score» | выполнено |

| Кандидат видит только свои приглашения и отклики | Проверки ролей `backend/app/api/deps.py`; `tests/test_security_matrix.py` | `cd backend && uv run pytest tests/test_security_matrix.py -q` | выполнено |

| Ранжирование с краткой объяснимостью | `backend/app/matching/explain.py`; карточка «за» и «против» | Открыть любого кандидата в подборке | выполнено |

| Кандидат без истории ФСП обрабатывается корректно | F = 0, в «против» не попадает; [VALIDATION.md](VALIDATION.md) п. 4.5 | Сравнить Анну и Илью в подборке | выполнено |
| Неподтверждённый грейд показывается со статусом и опускается в выдаче | `tests/test_api_unconfirmed_visibility.py` | Найти в банке кандидата со статусом «не подтверждён» | выполнено |

## 4. Правила видимости и контакт

| Требование | Где реализовано | Как проверить | Статус |
|---|---|---|---|
| Вилка в рублях обязательна в вакансии и приглашении, подписано «на руки» или «до вычета НДФЛ» | `config/contact.yaml` (`salary`); `SalaryOut` в API | Создать приглашение без вилки: будет отказ | выполнено |
| Приглашение содержит предложение, вилку, компанию и способ связи | `backend/app/services/contact/schemas.py`; `/candidate/invitations/{id}` | Открыть приглашение | выполнено |
| Статусы приглашений и откликов видны обеим сторонам | `InvitationStatus`, `ApplicationStatus`; канбан работодателя | Пройти «Да, если…» с обеих сторон | выполнено |
| Регистрация по email с подтверждением адреса | `/auth/register`, `/verify-email`; письма в Mailpit `:8025` | Зарегистрироваться при `VZ_DEMO_AUTO_VERIFY_EMAIL=false`. В демо-режиме код отключён для удобства жюри | частично |
| Верификация компании и модерация вакансий не обязательны в MVP | Добровольная метка «Проверенная компания»; жалобы и автосигналы; [TRUST_AND_SAFETY.md](TRUST_AND_SAFETY.md) | `/employer/company` | выполнено |

| Смена грейда ограничена по времени; провал не сжигает попытку на ступень ниже | `config/testing.yaml` (`change_interval_days`, `retake_days`) | `/candidate/qualification` | выполнено |
