# «Взаимно» — платформа обратного подбора ИТ-специалистов (хакатон ЛЦТ-2026, спецтрек ФСП)

Кандидат проходит опрос → выбирает грейд → адаптивный тест (CAT, одноразовые клоны заданий) → получает категорию «специализация × грейд».
Работодатель описывает потребность текстом с обязательной вилкой → система рекомендует категории и строит слепую объяснимую подборку →
приглашение с зарплатой → «Да / Да, если… / Нет» → контакты раскрываются только после взаимного «да».

## Где что лежит
- `backend/` — FastAPI + SQLAlchemy 2 + PostgreSQL (pgvector). Пакет `app`:
  - `app/testing/` — IRT/CAT-движок (`irt.py`, `cat.py`), банк семейств заданий `app/testing/bank/` (контракт в `bank/base.py`).
  - `app/matching/` — разбор брифа, скоринг Score, объяснения, версии подборки.
  - `app/fsp/` — модель достижений ФСП, VSS, адаптер `FSPProvider`.
  - `app/api/`, `app/models/`, `app/core/` — HTTP-слой, ORM, настройки/безопасность.
- `backend/eval/` — генератор синтетической популяции с латентной истиной + `make validate`.
- `services/fsp-mock/` — мок реестра ФСП (FastAPI). `deploy/keycloak/` — realm `fsp` (ФСП ID).
- `config/*.yaml` — ВСЕ веса, пороги, квоты и справочники. В коде магических чисел нет — читаем конфиг.
- `frontend/` — React + Vite + TS + Tailwind + shadcn/ui (цвета ФСП).
- Конфиденциально и НЕ в git: `materials/` (ТЗ), `research/`, `_internal/` (концепция `_internal/design/01-concept.md`, спецификации `spec-*.md`, `DECISIONS.md`).

## Команды
- Бэкенд-тесты: `cd backend && uv run pytest -q`
- Линт: `cd backend && uv run ruff check .`
- Валидация: `cd backend && uv run python -m eval.validate`

## Правила
- Тексты интерфейса, сообщения API для пользователя, объяснения — на русском. Код, идентификаторы — на английском.
- Детерминизм: всё случайное — через явный `random.Random(seed)` / `numpy.random.default_rng(seed)`. Без глобального random.
- LLM не вызывается в рантайме теста и в ранжировании. LLM — только через шлюз `app/llm/` с детерминированным fallback.
- Резюме и самоописание НЕ влияют ни на категорию, ни на Score (только серые «заявлено»-чипы).
- Отсутствие истории ФСП — не штраф: F = 0, в «против» не попадает никогда.
- Контакты/ПДн кандидата работодателю — только при активном раскрытии (DTO `CandidateBlind` vs `CandidateDisclosed`).
- Каждый модуль сопровождается pytest-тестами; контрольные примеры из спецификаций — обязательные тесты.
- Сложные места — короткий комментарий «почему», со ссылкой на раздел спецификации.
- Никаких реальных брендов компаний и реальных ФИО в демо-данных. Компании вымышленные.
- Не трогай `pyproject.toml`/`package.json` без необходимости; новые зависимости — только с открытой лицензией (MIT/BSD/Apache).
- Никогда не коммить и не цитируй ТЗ дословно в публичных файлах (п. 6.3.4 регламента).
