# fsp-mock — демо-реестр достижений ФСП

Публичного API реестра у ФСП нет, протоколы публикуются сканами PDF. Этот сервис — **предлагаемый ФСП
контракт API реестра** (OpenAPI) и его мок с синтетическими данными. Бэкенд «Взаимно» ходит в него через
`HttpFSPProvider`; на тот же контракт переключается, когда появится настоящий API (концепция §6.5).

Все спортсмены, команды и номера ЕКП **вымышлены**: фамилии собраны из ИТ-терминов («Байтов», «Кэшева»),
в номере ЕКП после года стоит «99» — признак синтетики. В UI данные помечаются «Демо-реестр ФСП».

## Запуск

```bash
cd services/fsp-mock
pip install -r requirements.txt
uvicorn fsp_mock.main:app --port 8001
# документация (на русском): http://localhost:8001/docs
```

Docker (в `docker-compose.yml` это сервис `fsp-mock`, порт 8001 внутри и снаружи контейнера;
бэкенд ходит в него по `VZ_FSP_REGISTRY_URL=http://fsp-mock:8001`):

```bash
docker build -t vzaimno/fsp-mock services/fsp-mock
docker run --rm -p 8001:8001 -e FSP_MOCK_PUBLIC_URL=http://localhost:8001 vzaimno/fsp-mock
```

## API

Все `/v1/*` требуют `Authorization: Bearer <токен>`; демо-токен — `demo-fsp-registry-token`.

| Метод | Путь | Что отдаёт |
|---|---|---|
| GET | `/v1/athletes/{sub}` | Спортсмен: ФИО, дата рождения, регион. `sub` — из ФСП ID |
| GET | `/v1/athletes/{sub}/achievements` | Результаты + соревнования, на которые они ссылаются, разряды, роли судьи и тренера |
| GET | `/v1/competitions/{ekp}` | Соревнование по номеру ЕКП и результаты спортсменов реестра по местам |
| GET | `/protocols/{ekp}` | HTML-страница протокола (ссылка `protocol_url`), без токена |
| GET | `/health` | Проверка работоспособности |

Модели — `fsp_mock/contract.py`, это **точная копия** `backend/app/fsp/models.py` (источник истины).
После правки контракта в бэкенде: `python -m fsp_mock sync-contract`. Тест `test_fsp_mock.py` падает,
если копии разошлись.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `FSP_MOCK_TOKENS` | `demo-fsp-registry-token` | допустимые bearer-токены через запятую |
| `FSP_MOCK_PUBLIC_URL` | `http://localhost:8001` | внешний адрес для `protocol_url` |
| `FSP_MOCK_SEED` | `20261011` | seed генератора |
| `FSP_MOCK_AS_OF` | текущее время UTC | зафиксировать `as_of` в ответах (ISO 8601) |

## Данные (`fsp_mock/generator.py`)

Детерминированный генератор: один seed — байт-в-байт один реестр, от текущей даты не зависит
(точка отсчёта — 05.10.2026).

- **60 спортсменов**: основная и иногда вторая дисциплина, «сила», функция в продуктовой команде
  (backend, frontend, fullstack, ML, дизайн, менеджер продукта), 7 несовершеннолетних.
- **25 соревнований**, по 5 на дисциплину (алгоритмическое, продуктовое, БАС, робототехника, ИБ, коды ВРВС):
  международные, ЧР, ПР, финалы и отборы КР (связаны `parent_ekp`), всероссийский хакатон,
  межрегиональные, региональные, муниципальные и студенческие; личный и командный зачёт.
- **Результаты**: место из N (в сетке на выбывание — диапазоны 5–8, 9–16), балл там, где он есть,
  команды с капитаном, участниками и запасными.
- **Разряды** по упрощённым нормам ЕВСК: МС пожизненно, КМС на 3 года, I–III на 2 года, номер приказа,
  кем присвоен; один истёкший разряд.
- **Роли**: судья-эксперт (1К), главный судья (ВК), тренеры — в том числе тренер без своих результатов.
- **Состояния из концепции §6.4**: 6 спортсменов без результатов, 2 — только с разрядом,
  3 — только с результатами, ждущими протокола (3 соревнования сентября 2026 с `protocol_status=pending`).

## Производные файлы

```bash
python -m fsp_mock export
```

пересобирает (их синхронность с генератором проверяют тесты бэкенда):

- `backend/app/fsp/data/demo_registry.json` — снимок реестра для встроенного провайдера бэкенда
  (`InProcessFSPProvider`: демо работает, даже если мок не поднят);
- `deploy/keycloak/realm-fsp.json` — realm `fsp` с 30 демо-пользователями, у которых `id` = `sub`
  спортсмена; таблица соответствия — в `deploy/keycloak/README.md`.
